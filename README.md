### Quick Start

```bash
git clone https://github.com/<user>/v0-ipod
npm install
npm run dev
```

### Available Scripts

| Script | Description |
|---|---|
| `npm run dev` | Development server (with portless — `https://ipod.localhost`) |
| `npm run dev:raw` | Development server (`http://localhost:3000`) |
| `npm run build` | Production build |
| `npm run validate` | Full validation (board check + lint + type-check) |
| `npm run test` | Run all tests |
| `npm run lint` | Lint with oxlint |
| `npm run type-check` | TypeScript type check |
| `npm run storybook` | Run Storybook locally |
